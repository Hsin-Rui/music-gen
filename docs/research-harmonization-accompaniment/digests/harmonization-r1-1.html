    Digest: Melody harmonization (melody to chords), r1-1¶

    Scope: open models and tools that take a symbolic melody and output chord labels, from 2019 to 2026. Accessed 2026-11-21 for every source. I used 20 tool calls. Commit dates were not visible on any GitHub page I fetched, so "last activity" is unknown unless a row says otherwise.

    Findings¶

    # Claim Source URL Publisher pub_date Accessed Conf. Class
    1 MelodyT5 is a 113M-parameter score-to-score encoder-decoder. It works in ABC notation and has a %%harmonization task tag. The output chords are quoted ABC chord symbols, including 7ths and slash chords (inversions), e.g. "G#m7/B" and "F#7". https://github.com/sanderwood/melodyt5 ; https://arxiv.org/html/2407.02277 GitHub / arXiv (ISMIR 2024) 2024-07 2026-11-21 high capability
    2 MelodyT5 code is MIT-licensed. The weights are downloadable from HF (sander-wood/melodyt5/weights.pth). The repo states no licence for the weights. https://github.com/sanderwood/melodyt5 ; https://huggingface.co/sander-wood/melodyt5 GitHub / HF 2024 2026-11-21 high (code), low (weights licence) licence
    3 The MelodyT5 setup pins PyTorch 1.13.1 cu116 and Python 3.7.9, and training defaults to 8 GPUs. Mac CPU/MPS inference is not documented. At 113M parameters I expect CPU inference to be feasible, but that is unverified. https://github.com/sanderwood/melodyt5 GitHub 2024 2026-11-21 med compat
    4 MelodyT5 was trained on about 42k harmonization instances from ABC Notation, JSB Chorales, The Session, FolkWiki and Nottingham. That is folk, classical chorale and Western material. No Chinese collections (e.g. ESAC) are listed. https://arxiv.org/html/2407.02277 arXiv 2024-07 2026-11-21 high capability
    5 MelodyT5 versus STHarm on harmonization: CTnCTR 0.8438 vs 0.8607, PCS 0.5084 vs 0.4863, MCTD 1.0320 vs 1.0610. MelodyT5 wins on PCS and MCTD and loses on CTnCTR. An A/B listening test favoured MelodyT5, but the text gives no vote counts. https://arxiv.org/html/2407.02277 arXiv 2024-07 2026-11-21 high evaluation
    6 EMO_Harmonizer (arXiv 2407.20176) does emotion-conditioned harmonization with a functional (key-relative) representation. It is pre-trained on HookTheory and fine-tuned on EMOPIA. Checkpoints are on Google Drive and output is MIDI. https://github.com/Yuer867/EMO_Harmonizer ; https://arxiv.org/html/2407.20176 GitHub / arXiv 2024-07 2026-11-21 high capability
    7 EMO_Harmonizer has no LICENSE file. It requires pytorch-fast-transformers and recommends CUDA 10.2, so Mac use is doubtful because that library's CUDA/C++ build is a known pain point (unverified on Mac). https://github.com/Yuer867/EMO_Harmonizer GitHub 2024 2026-11-21 med licence / compat
    8 "Pay (Cross) Attention to the Melody" (Kaliakatsos-Papakostas et al., arXiv 2601.16150, Jan 2026) is a single-encoder masked harmonizer with an FF curriculum. It is trained on HookTheory and also evaluated on jazz standards. The authors say it beats baselines on almost all metrics, with the largest gains out of domain. https://arxiv.org/abs/2601.16150 arXiv 2026-01-22 2026-11-21 high capability / evaluation
    9 The code for item 8 is Apache-2.0 at NeuraLLMuse/SingleEncoderMHCrossAttention. Melody input is a pitch-class pianoroll at quarter-note resolution. No pretrained weights or requirements are listed. https://github.com/NeuraLLMuse/SingleEncoderMHCrossAttention GitHub 2026 2026-11-21 high licence
    10 The same group published a diffusion-inspired masked LM for harmony on a fixed time grid (Applied Sciences 15(17):9513, 2025). A search snippet says it compares against BART and GPT-2 harmonizers using CTnCTR, PCS and MCTD. The full text was blocked (HTTP 403). https://doi.org/10.3390/app15179513 MDPI 2025 2026-11-21 low evaluation
    11 B* constrained decoding (beam search + A* + backtracking) forces user-given chords into the output of pretrained harmonization transformers (AIMC 2025, CC BY 4.0, Zenodo 10.5281/zenodo.16948248). The abstract does not name the models. https://arxiv.org/abs/2512.07627 arXiv / AIMC 2025 2025-12-08 2026-11-21 med capability
    12 rsy1026/harmonizers_transformer implements STHarm, VTHarm and rVTHarm (IEEE Access 2022). It trains on CMD and HLSD (HookTheory) and reports CHE, CC, CTR, PCS, CTD, MTD, LD, TPSD and DICD. It has no licence and no pretrained weights (you train them yourself), and the README assumes a CUDA device. https://github.com/rsy1026/harmonizers_transformer GitHub 2022 2026-11-21 high capability / licence
    13 AccoMontage2 (ISMIR 2022) is MIT-licensed. It has a harmonization module that produces a chord progression from a MIDI melody, then arranges an accompaniment. It needs a tonic and mode, works only in 4/4, takes 4- or 8-bar phrase segmentation (e.g. "A8B8A8B8") and offers chord styles pop_standard, pop_complex, dark and r&b. Its chord library is a reorganized Niko dataset of 5k+ progressions. It has a Flask GUI and the README mentions no GPU. https://github.com/billyblu2000/AccoMontage2 GitHub 2022 2026-11-21 high capability / licence
    14 SurpriseNet (ISMIR 2021) is a CVAE harmonizer conditioned on a user "surprise" contour and trained on the HookTheory Lead Sheet Dataset. I did not check its licence or weights. https://github.com/scmvp301135/SurpriseNet ; https://archives.ismir.net/ismir2021/paper/000012.pdf GitHub / ISMIR 2021 2026-11-21 med capability
    15 Amuse (Kim, Lee, Donahue, arXiv 2412.18940) turns keywords into chords using a HookTheory chord prior plus GPT-4o and needs an OpenAI API key. It is not a melody harmonizer, so it is out of scope. https://github.com/elianakim/Amuse GitHub / arXiv 2024-12 2026-11-21 high ecosystem
    16 SongComposer (ACL 2025) is an LLM for lyric-to-melody, melody-to-lyric, continuation and text-to-song. Its listed tasks include no harmonization or chord output. https://github.com/pjlab-songcomposer/songcomposer ; https://aclanthology.org/2025.acl-long.352 GitHub / ACL 2024-02 / 2025 2026-11-21 med ecosystem
    17 Yeh et al., "Automatic Melody Harmonization with Triad Chords: A Comparative Study" (JNMR 50(1)), compares template matching, HMM, a genetic algorithm and two deep models. It uses 9,226 melody/chord pairs, a 48-triad vocabulary, six objective metrics and 202 listeners. The abstract page gives no winner and no code link. It is the canonical baseline set and metric suite: CTnCTR, PCS and MCTD originate there or are reused from it (my belief, not verified). https://arxiv.org/abs/2001.02360 arXiv / JNMR 2020-01 (rev. 2021-04) 2026-11-21 high (design), low (metric origin) evaluation
    18 CPFG-Net (arXiv 2511.14600, Nov 2025) is a conditional VAE that predicts perceptual features from a melody and maps them to a chord progression. I did not check code, licence or weights. https://arxiv.org/abs/2511.14600 arXiv 2025-11-18 2026-11-21 med capability
    19 Bitsonic Melody Harmonizer is a free, closed-source MIDI melody-to-chord plugin (VST3/AU on macOS) entered in the KVR Developer Challenge 2026. It could serve as a non-research baseline or listening reference. https://www.kvraudio.com/news/kvrdc26-bitsonic-melody-harmonizer---free-harmony-generator-plugin-for-macos-windows-and-linux-au-and-vst3-67633 KVR Audio 2026 2026-11-21 med ecosystem
    20 Melodica (bivex/melodica, June 2026) is an open Python orchestral composition engine with a melody harmonizer. A forum commenter criticized its large volume of AI-generated code, so treat it as experimental. https://vi-control.net/community/threads/melodica-python-orchestral-composition-engine-with-harmonization-open-source-seeking-contributors.172916/ VI-Control forum 2026-06 2026-11-21 low ecosystem
    21 The HookTheory Lead Sheet Dataset (wayne391/lead-sheet-dataset) is the common training source for HookTheory-based harmonizers (STHarm, SurpriseNet, EMO_Harmonizer, the RL harmonizer in MDPI Electronics 10(20):2469). https://github.com/wayne391/lead-sheet-dataset ; https://www.mdpi.com/2079-9292/10/20/2469 GitHub / MDPI 2019-2021 2026-11-21 med ecosystem

    Leads worth chasing¶

    • Pick for the prototype: MelodyT5. It has open weights and an MIT code licence. Its examples output 7ths and inversions, and its ABC output can be parsed easily (e.g. with music21). It needs a modern-PyTorch/MPS smoke test and a check on the weights licence (HF card).
    • Baseline with a downstream path: AccoMontage2 gives chords plus accompaniment end to end, with a CPU GUI and MIT licence. Check its requirements.txt for Mac blockers, and check AccoMontage3.
    • Kaliakatsos-Papakostas / NeuraLLMuse group (2025-2026): look for released BART/GPT-2 harmonizer checkpoints (possibly on HF), the Zenodo record for B*, and the Applied Sciences paper (open access, try PMC/ResearchGate).
    • Check EMO_Harmonizer's paper for chord vocabulary and results, and whether pytorch-fast-transformers can be replaced with a vanilla attention layer for Mac.
    • Get the Yeh et al. comparative study's results table and find any HMM/template baseline code. It is the standard evaluation protocol; check whether metric code (CTnCTR, PCS, MCTD) is packaged anywhere.
    • Check for Chinese/East-Asian harmonization data and models, e.g. POP909-derived chord labels or Chinese pop lead sheets. None appeared in this run.
    • Check CPFG-Net and SurpriseNet repos for licences and weights.
