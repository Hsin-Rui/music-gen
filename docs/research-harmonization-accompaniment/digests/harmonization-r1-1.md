# Digest: Melody harmonization (melody to chords), r1-1

Scope: open models and tools that take a symbolic melody and output chord labels, from 2019 to 2026. Accessed 2026-11-21 for every source. I used 20 tool calls. Commit dates were not visible on any GitHub page I fetched, so "last activity" is unknown unless a row says otherwise.

## Leads worth chasing

- Pick for the prototype: MelodyT5. It has open weights and an MIT code licence. Its examples output 7ths and inversions, and its ABC output can be parsed easily (e.g. with music21). It needs a modern-PyTorch/MPS smoke test and a check on the weights licence (HF card).
- Baseline with a downstream path: AccoMontage2 gives chords plus accompaniment end to end, with a CPU GUI and MIT licence. Check its requirements.txt for Mac blockers, and check AccoMontage3.
- Kaliakatsos-Papakostas / NeuraLLMuse group (2025-2026): look for released BART/GPT-2 harmonizer checkpoints (possibly on HF), the Zenodo record for B*, and the Applied Sciences paper (open access, try PMC/ResearchGate).
- Check EMO_Harmonizer's paper for chord vocabulary and results, and whether `pytorch-fast-transformers` can be replaced with a vanilla attention layer for Mac.
- Get the Yeh et al. comparative study's results table and find any HMM/template baseline code. It is the standard evaluation protocol; check whether metric code (CTnCTR, PCS, MCTD) is packaged anywhere.
- Check for Chinese/East-Asian harmonization data and models, e.g. POP909-derived chord labels or Chinese pop lead sheets. None appeared in this run.
- Check CPFG-Net and SurpriseNet repos for licences and weights.
