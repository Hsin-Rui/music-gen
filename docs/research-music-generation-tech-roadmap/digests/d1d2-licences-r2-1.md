# D1/D2 licence verification, round 2, digest 1
Accessed 2026-11-19. Sources were checked live through the GitHub REST API (`/repos/{r}` licence field and raw README/LICENSE files), the Hugging Face API (`cardData.license`, tags, gated flag), the Zenodo REST API, the official dataset pages, and WebSearch/WebFetch for the legal items. "GH API" means the licence GitHub detected from the repo's LICENSE file. "HF API" means the licence declared in the model card's YAML header.

## Leads
- **Conflict:** YourMT3 code is GPL-3.0 (GitHub) but the checkpoints are Apache-2.0 (HF). Check whether the HF Space code is also GPL, and what licences the training data (Slakh, MusicNet, and others) carry.
- **Provenance risk:** AMT weights are Apache-2.0 but were trained on "450k commercial music records". ACE-Step 1.5 training data is undisclosed or unchecked. After GEMA v Suno ("the model itself infringes"), a permissive weights licence does not equal commercial safety in the EU. Next: read the ACE-Step 1.5 tech report's data section.
- Get a second source for GEMA v Suno (31 Jul 2026), for example the GEMA press release or juris/beck-aktuell. Also find out whether Suno appealed, and the OLG München docket or hearing date for OpenAI.
- Read the Aria-MIDI DISCLAIMER.md and LICENSE.md. Read the Llama 3.2 licence clauses that apply to MIDI-LLM.
- Check the PDMX.csv licence column: are any songs CC-BY (needing attribution) rather than PD or CC0 inside `no_license_conflict`?
- Find the US Copyright Office generative AI training report (Part 3, May 2025 pre-publication) and whether a final version has been issued. Not covered this round.
