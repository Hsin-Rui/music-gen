### Q4 Fine-tuning reports
- The NotaGen repo is **MIT**-licensed (last push 2025-04). Per search excerpts of its README, it includes a fine-tuning recipe with a small demo dataset of Schubert lieder from OpenScore Lieder, plus ABC↔MusicXML conversion. The authors' demo page reports fine-tuning on **about 100 popular songs**, followed by RL, to get a pop style. Compute figures for that fine-tune were not found. | GitHub API; NotaGen demo page / repo (via search summary) | https://github.com/ElectricAlexis/NotaGen ; https://electricalexis.github.io/notagen-demo | Wang et al. | 2025 | accessed 2026-11-19 | high (licence), medium (recipe, ~100 songs; README not read directly) | licence / method | paper **peer-reviewed (IJCAI 2025)**

The repo has preprocessing and sampling code but **no training code**, and the authors point to the Levanter codebase for training. The Large 780M model was trained on Lakh + MetaMIDI + transcripts of FMA and 450k commercial records. That data provenance matters for commercial use. No third-party fine-tuning report was found. ## Leads
1. **Licence stack conflict for Gezi-opera SVS.** The FT-GAN code has no licence, the GOAT data is NC-SA with an indemnity clause, and it depends on DiffSinger checkpoints whose own licence is unverified. Openvpi/DiffSinger (Apache-2.0) is the cleaner base, but its pretrained models and voicebanks may carry separate terms. Next: check the openvpi model and voicebank terms, and email the FT-GAN authors to ask for a code licence.
2. **AMT data provenance.** The Large model was trained on "450k commercial records" transcripts, while the Apache-2.0 model licence covers only the code and weights. Assess the commercial-use risk. The small Lakh-only models may be safer.
3. Read the NotaGen README fine-tune section directly to get GPU and hours numbers. Look for NotaGen GitHub issues about fine-tuning on folk or non-Western ABC (Chinese jianpu → ABC is a candidate pipeline).
4. Read SongSong / OpenSongSong (2602.24071) for the code and data licence. It is the most recent Chinese-traditional generator found, at 29.9 h.
5. Japanese: search the Japanese-language literature (e.g. "邦楽 データセット", "尺八 自動採譜", the 情報処理学会 SIGMUS proceedings) and NII / Geidai digital archives. English searches found nothing MIR-ready.
6. Chinese ethnic minority archives: not searched this run because of budget. Candidates to chase: the Chinese Academy of Arts music research institute sound archive and the CCMusic database (licence check).
7. Academia Sinica: the reuse terms must come from the museum's or the Taiwan Ethnography Video and Audio Archive's general copyright page, or from the contact address. Indigenous consent norms (CARE principles, the Indigenous Peoples Basic Law) probably apply beyond copyright.
