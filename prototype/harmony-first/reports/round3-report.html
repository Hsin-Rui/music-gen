一、指標怎麼算

為什麼改：第二輪的分數把「忠於和弦」和「不抄旋律」等項目加在一起比高低，結果常挑到幾乎照抄柱式和弦提示的那份。R5 研究發現「忠於和弦」和「不照抄提示」會互相拉扯，所以這一輪把「忠於和弦」改成門檻：先淘汰不合格的，剩下的再比「有沒有變化、守不守規則」。

門檻（五道都過才算通過；起始值都可以調，這輪不調）：

門檻白話條件
彈得夠多不能幾乎什麼都沒彈音數 ≥ 小節數，而且空拍比例 ≤ 25%。一拍裡只要有任何伴奏音正在響就不算空拍（延長的和弦也算）。
不抄旋律不能只是把旋律重彈一次或平移和旋律同時起音、距離固定（同音、八度、平行三度等）的伴奏音比例 < 0.5（沿用第二輪的「抄旋律」）。
不照抄提示不能只是把柱式和弦提示原樣彈出來抄襲程度 = 2 × 配對數 ÷（伴奏音數＋提示音數）< 0.5。配對：音名相同（不管八度）、起音差 ≤ 40 毫秒，一個音只能配一次。提示原樣彈出來 = 1.0。
守住和弦要照和弦表走，不亂彈調外音逐拍和弦吻合率 ≥ 0.7（一拍裡響著的伴奏，至少一半時間是當下和弦的音，這一拍才算吻合），而且調外音 ≤ 5%。
彈得到一個人兩隻手彈得出來同時起音的一組音，一隻手彈得下，或能切成左右兩手、每隻手 ≤ 5 個音且跨度 ≤ 14 個半音，就算彈得到。兩隻手怎麼切都不行的，就不合格。

排名（只在通過門檻的候選之間排，每項 1 = 最好，同分同名次；三項名次加總最小的勝出；再同分就選「不像提示」比較低的，再同分選編號小的）：

項目白話怎麼算
不像提示越不像柱式和弦提示越好兩個數的平均：① 音符比對 F1（音高相同、起音差 ≤ 50 毫秒、結束時間也接近才算配對）；② 節奏格子相似度（十六分音符格子上「有沒有起音」的餘弦相似度）。越低越好。
不違規少一點和聲規則上的毛病低音和旋律之間的平行五度、平行八度（每個旋律音的比例），加上刺耳重疊（旋律與伴奏同時響小二度、三全音、大七度的時間比例）。越低越好。
低音正確換和弦時，最低的音是不是和弦的低音每次換和弦，看換和弦後半拍內起音的最低伴奏音，音名是不是和弦的低音（斜線和弦看斜線後面的音）。越高越好。這一項是自訂的，沒有文獻依據。

退回：如果一格裡沒有任何一份過全部門檻，就在「擋掉的門檻數最少」的那幾份裡用同樣方法排名，並標成「退回」。

Claude、Gemini 寫伴奏每格只有一份，指標照樣計算、顯示，但不參與挑選。

六、和計畫字面不同的地方

  • 空拍看「正在響」，不看「起音」：MusPy 的空拍是數起音，但那樣會把「一個和弦延長一整小節」的織體判成空拍、擋掉。這裡改成「一拍裡有任何伴奏音在響就不算空」。
  • 「彈得到」是兩隻手的檢查：計畫的表寫「同時發聲 ≤ 5 個、跨度 ≤ 14 個半音」，照字面當成一隻手，會擋掉所有「低音＋和弦」的織體，連 Claude、Gemini 的規劃也過不了。計畫的本意是「彈得到」，所以改成兩隻手的檢查：試過所有左右手的切法，只要有一種切法兩手都彈得下就合格。
  • 只看「起音」相同的一組音：彈得到的檢查只看同時按下的音，不管前面還在延長的音（例如踏板留著的低音）。
  • 平行五八度只看相鄰的兩個旋律音：兩個旋律音中任何一個當下沒有伴奏音在響，這一對就跳過。比例的分母是全部旋律音數。
  • 舊指標挑的那份取自第二輪 candidates/scores.json 的 best（它是候選清單的索引，再對應到編號）。
  • AccoMontage 常被「彈得到」擋下：它的伴奏來自 POP909 流行歌鋼琴譜，常有一次橫跨三個音域的大和弦（例如低音 37、中間 52–57、上面 67–69），左手撐不開；而且只要整首有一個這樣的和弦，整份就不合格。這是門檻的結果，不是程式錯誤，但門檻值（5 音、14 半音）沒有文獻依據，聽過之後可以再調。
